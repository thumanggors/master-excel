## Matematika & Pembulatan

| Formula | Fungsi | Contoh | Versi |
|---|---|---|---|
| SUM | Menjumlahkan angka | `=SUM(A2:A10)` | |
| SUMIF | Menjumlahkan dengan 1 kriteria | `=SUMIF(A2:A10,"Jakarta",C2:C10)` | |
| SUMIFS | Menjumlahkan dengan banyak kriteria | `=SUMIFS(C2:C10,A2:A10,"Jakarta",B2:B10,"Hardware")` | |
| SUMPRODUCT | Mengalikan array lalu menjumlahkan | `=SUMPRODUCT(B2:B10,C2:C10)` | |
| PRODUCT | Mengalikan semua angka | `=PRODUCT(B2:D2)` | |
| ABS | Nilai mutlak | `=ABS(C2-B2)` | |
| MOD | Sisa pembagian | `=MOD(B2,24)` | |
| POWER | Pangkat | `=POWER(1.08,3)` | |
| SQRT | Akar kuadrat | `=SQRT(900000)` | |
| INT | Bulatkan ke bawah ke bilangan bulat | `=INT(B2/C2)` | |
| TRUNC | Potong desimal | `=TRUNC(A2,2)` | |
| ROUND | Bulatkan ke terdekat | `=ROUND(A2*11%,0)` | |
| ROUNDUP | Bulatkan selalu ke atas | `=ROUNDUP(47/12,0)` | |
| ROUNDDOWN | Bulatkan selalu ke bawah | `=ROUNDDOWN(A2/10000,0)` | |
| MROUND | Bulatkan ke kelipatan terdekat | `=MROUND(A2,500)` | |
| CEILING | Naik ke kelipatan | `=CEILING(A2,1)` | |
| CEILING.MATH | Naik ke kelipatan (versi baru) | `=CEILING.MATH(A2)` | 2013+ |
| FLOOR | Turun ke kelipatan | `=FLOOR(A2,0.5)` | |
| FLOOR.MATH | Turun ke kelipatan (versi baru) | `=FLOOR.MATH(A2)` | 2013+ |
| RAND | Angka acak 0 sampai 1 | `=RAND()` | |
| RANDBETWEEN | Angka acak bulat dalam rentang | `=RANDBETWEEN(1,100)` | |
| SUBTOTAL | Total yang mengabaikan baris terfilter | `=SUBTOTAL(9,C2:C100)` | |
| AGGREGATE | Total yang bisa mengabaikan error | `=AGGREGATE(9,6,C2:C100)` | |

## Statistik & Hitung Data

| Formula | Fungsi | Contoh | Versi |
|---|---|---|---|
| AVERAGE | Rata-rata | `=AVERAGE(B2:B10)` | |
| AVERAGEIF | Rata-rata dengan 1 kriteria | `=AVERAGEIF(B2:B10,"Sales",D2:D10)` | |
| AVERAGEIFS | Rata-rata dengan banyak kriteria | `=AVERAGEIFS(D2:D10,B2:B10,"Sales",C2:C10,"Tetap")` | |
| MEDIAN | Nilai tengah | `=MEDIAN(B2:B10)` | |
| MODE | Nilai paling sering muncul | `=MODE(B2:B10)` | |
| MODE.SNGL | Modus (nama baru MODE) | `=MODE.SNGL(B2:B10)` | |
| MAX | Nilai terbesar | `=MAX(B2:B10)` | |
| MIN | Nilai terkecil | `=MIN(B2:B10)` | |
| MAXIFS | Nilai terbesar dengan kriteria | `=MAXIFS(G2:G11,C2:C11,"Banten")` | 2019+ |
| MINIFS | Nilai terkecil dengan kriteria | `=MINIFS(F2:F11,H2:H11,"DELAY")` | 2019+ |
| LARGE | Nilai terbesar ke-k | `=LARGE(B2:B10,2)` | |
| SMALL | Nilai terkecil ke-k | `=SMALL(B2:B10,2)` | |
| RANK | Peringkat | `=RANK(B2,$B$2:$B$10,0)` | |
| RANK.EQ | Peringkat (nama baru RANK) | `=RANK.EQ(B2,$B$2:$B$10,0)` | |
| COUNT | Hitung cell berisi angka | `=COUNT(B2:B10)` | |
| COUNTA | Hitung cell tidak kosong | `=COUNTA(A2:A10)` | |
| COUNTBLANK | Hitung cell kosong | `=COUNTBLANK(B2:B10)` | |
| COUNTIF | Hitung dengan 1 kriteria | `=COUNTIF(H2:H10,"DELAY")` | |
| COUNTIFS | Hitung dengan banyak kriteria | `=COUNTIFS(C2:C10,"Banten",H2:H10,"DELAY")` | |
| STDEV.S | Standar deviasi sampel | `=STDEV.S(B2:B30)` | |
| VAR.S | Varians sampel | `=VAR.S(B2:B30)` | |
| PERCENTILE.INC | Nilai persentil | `=PERCENTILE.INC(B2:B30,0.9)` | |
| QUARTILE.INC | Nilai kuartil | `=QUARTILE.INC(B2:B30,1)` | |
| CORREL | Koefisien korelasi dua data | `=CORREL(B2:B13,C2:C13)` | |
| FORECAST.LINEAR | Proyeksi tren linear | `=FORECAST.LINEAR(13,C2:C13,B2:B13)` | 2016+ |

## Logika

| Formula | Fungsi | Contoh | Versi |
|---|---|---|---|
| IF | Keputusan dua cabang | `=IF(B2>=75,"LULUS","REMEDIAL")` | |
| IFS | Keputusan banyak kondisi | `=IFS(B2>=90,"A",B2>=80,"B",TRUE,"C")` | 2019+ |
| AND | Semua kondisi benar | `=AND(B2>=100%,C2>=95%)` | |
| OR | Minimal satu kondisi benar | `=OR(B2>=1000000000,C2="Key Account")` | |
| NOT | Membalik logika | `=NOT(B2="Closed")` | |
| XOR | Tepat satu (jumlah ganjil) kondisi benar | `=XOR(B2="Ya",C2="Ya")` | 2013+ |
| SWITCH | Pencocokan dari daftar | `=SWITCH(A2,"JKT","Jakarta","BDG","Bandung","Lainnya")` | 2019+ |
| IFERROR | Pengganti untuk semua error | `=IFERROR(C2/B2,0)` | |
| IFNA | Pengganti khusus #N/A | `=IFNA(VLOOKUP(E2,A2:B10,2,FALSE),"-")` | 2013+ |

| PROPER | Huruf awal kata kapital | `=PROPER(A2)` | |
| TRIM | Buang spasi berlebih | `=TRIM(A2)` | |
| CLEAN | Buang karakter tak tercetak | `=CLEAN(A2)` | |

## Lookup & Referensi

| Formula | Fungsi | Contoh | Versi |
|---|---|---|---|
| VLOOKUP | Cari vertikal | `=VLOOKUP(J2,$A$2:$G$7,2,FALSE)` | |
| HLOOKUP | Cari horizontal | `=HLOOKUP("Zona 2",$A$1:$D$3,2,FALSE)` | |
| LOOKUP | Cari mendekati di data urut | `=LOOKUP(D2,A2:A5,B2:B5)` | |
| INDEX | Ambil isi berdasarkan posisi | `=INDEX(A2:G7,4,2)` | |
| MATCH | Cari posisi | `=MATCH("MTR-004",A2:A7,0)` | |
| XLOOKUP | Lookup modern | `=XLOOKUP(J2,A2:A7,F2:F7,"Tidak ada")` | 2021+ |
| XMATCH | MATCH modern | `=XMATCH("OptiNet",C2:C7,0,-1)` | 2021+ |
| CHOOSE | Pilih dari daftar | `=CHOOSE(B2,"Tinggi","Sedang","Rendah")` | |
| OFFSET | Referensi bergeser dari titik awal | `=SUM(OFFSET(B1,1,0,3,1))` | |
| INDIRECT | Referensi dari teks | `=INDIRECT("Jan!B2")` | |
| ROW | Nomor baris | `=ROW()` | |
| ROWS | Jumlah baris range | `=ROWS(A2:A10)` | |
| COLUMN | Nomor kolom | `=COLUMN(C1)` | |
| COLUMNS | Jumlah kolom range | `=COLUMNS(A1:F1)` | |
| HYPERLINK | Membuat tautan | `=HYPERLINK("#Data!A1","Ke Data")` | |

:::
